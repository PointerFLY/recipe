# Hand images

`hands.png` was generated with the built-in image-generation tool for this game.
It is a transparent horizontal sprite sheet, ordered 0, 1, 2, 3, 4 fingers.
The application displays each fifth in a clipping window. The image element
uses its original 1983 × 793 dimensions and scales uniformly; the window clips
the other poses without stretching the selected hand.

Generation brief: photorealistic educational hand-pose sheet for children;
five equal columns of the same right hand, palm facing the camera, wrist down,
consistent scale, skin tone, and soft studio lighting. Poses are a closed fist,
index finger, index and middle, index/middle/ring, then four fingers with thumb
folded. Transparent background; no text, jewelry, or overlapping hands.

Each pose was visually checked for its finger count. Images supplement the
numeric count and accessible hand labels; game rules never depend on images.
